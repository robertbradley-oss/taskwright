# First practice walkthrough

For **Practice 02 · Check the source**, follow the same walkthrough sequence using its own [learner packet](simulation/model-match/PACKET.md) and [writing rubric](simulation/model-match/RUBRIC.md). Its choice answers are wireless, usb, and discuss. The detailed reset criteria below apply only to Practice 01. Save or copy a review before switching practices; page progress is not retained.

## Purpose

Observe whether a learner can find an unsupported AI instruction, use the exact source, and write a bounded customer response. All Morrow D2 material is fictional and must not be used as real product guidance.

## Run the experience

Open the local app using the README. Invite the learner to read the lesson, compare the draft with the manual, make the three evidence choices, and write a response before viewing feedback. Let them work without hints first; note any assistance you give. Review the explanation together, use the writing checklist, and invite a revision and optional reflection. Download the review if the learner wants to retain it. Refresh clears the page.

## Rubric

The app awards one point per supported choice: incorrect claim = 3-second reset; source for correction = §1; boundary = contact support after one failed reset. Total: 0–3 evidence points.

Review the actual written reply separately. For each criterion record **met**, **needs revision**, or **unclear**, with a brief quotation or explanation:

| Criterion | Evidence to look for |
| --- | --- |
| Accurate instruction | Powered on, new cartridge installed, hold for 8 seconds; no conflicting 3-second reset advice. |
| Supported boundary | Contact support if one correct attempt fails; no repeated resets or unnecessary replacement advice. |
| Clear customer communication | Understandable, considerate wording; green light conditional on success, without a guaranteed fix or invented diagnosis. |

The sample reply is one acceptable wording, not a required script. A perfect choice score with an incorrect written instruction still needs revision. Self-checks are learner judgments, not facilitator ratings.

## What to learn from a walkthrough

Record where navigation or wording caused hesitation, whether source sections were easy to compare, whether feedback explained the error, and any difference between selected choices and written advice. Distinguish unaided first responses from assisted work and revisions. Save an initial review before revising if comparing attempts; later downloads describe the latest submitted response.

Use observations to improve this one flow and rubric before adding scenarios. Different but comparable assessment questions are needed before evaluating transfer or before-and-after performance. Do not infer a learning gain from a higher score on this repeated exercise. No recruitment or public reporting is initiated by this guide.

## When using AI simulations

Agents can exercise content and scoring without human participants. Give fresh agents only the learner-facing packet before capturing their first reply, record the role prompt and scenario revision, and retain their exact answers. Separate choice scores from source-based review of prose. Report whether any failure was deliberately prompted. Do not present text-only simulation as observed browser behavior or human learning evidence. The first run and its limitations are in `simulation/FINDINGS.md`.
