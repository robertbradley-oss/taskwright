03 · COMPARE FAIRLY
Same requirements. Two strategies.
Two fresh trials per configuration on all four development scenarios, with a first AI reply review for each completed attempt. ABBA order within each task. The frozen contract and both configuration snapshots are saved before any execution.
Uses the signed-in Codex allowance. Each support attempt is bounded to 180 seconds; each review to 90 seconds. Monetary cost is unavailable. The four reserved cases are excluded.
Selection rule and instruction difference
All 16 attempts and first reviews must complete compatibly. A configuration qualifies with 8/8 full-contract passes. Both qualifying means a tie. Unknowns and errors cannot count as passes. Reserved cases are never executed here.
